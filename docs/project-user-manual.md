# AI 项目助手 用户说明书

> 适用对象：本项目群成员与私聊用户  
> 版本：2026 年 11 月

AI 项目助手挂在 QQ 群和私聊里，围绕本项目提供问答、资料查询、代码修改和构建验证。群里 @ 它提问；私聊它，可以提交开发任务并跟踪结果。你不需要安装软件，也不需要做任何配置。本手册按当前项目配置编写。

## 一、助手如何分工

| 角色 | 在哪里 | 负责什么 |
|---|---|---|
| 项目主群助手 | 项目主群 | 关注项目讨论，答疑、查资料，把明确的开发需求交给编程助手；可把需要单独跟进的人转到私聊 |
| 仅 @ 群助手 | 设置为仅 @ 的群 | 只有被 @ 时回答；普通消息只作为上下文；不接开发任务，也不转接 |
| 私人助手 | 私聊 | 一对一服务，按管理员配置的项目工作；可记住偏好、跟踪任务、按需查看主群上下文 |
| 编程助手 | 后台 | 在限定的项目目录内改代码、构建、验证 |
| 管理员 | 后台 | 开通能力，审批项目主群的敏感操作 |

协作方式很简单：你提出需求，群助手或私人助手判断自己做还是交给编程助手，拿到结果后再回复你。

原则：

- 群聊是公开的，私聊是私密的；私聊内容不会跨用户转发。
- 项目主群以项目讨论为主，闲聊和无关内容可能不回复。
- 仅 @ 群只有被 @ 才触发，普通消息只作为上下文。
- 只做说得清的需求；完全看不出目标时会先问一句，不替你猜。

## 二、工具用法

下面按用途列出当前可用的工具。具体以实际开通为准；未开通时助手会说明。

### 2.1 资料与图片

| 能力 | 怎么用 | 结果 |
|---|---|---|
| 项目问答 | 直接提问 | 解释代码、方案、报错和项目约定 |
| 读网页 | 发链接 | 读取并总结网页；图片链接会转成图片 |
| 联网搜索 | “搜一下……” | 返回搜索结果与摘要 |
| 查百科 | “查一下萌娘百科……” | 查询人物、角色、作品条目 |
| 看图 | 发截图或图片 | 识别文字、界面、报错、人物等 |
| 看头像 | “看看我的头像”“看看群头像” | 获取并识别头像；群内是否可用取决于平台 |
| 发图/表情 | “把这张图发出来”“发个表情” | 发送已有图片或配置好的表情；不能凭空生成图片 |

### 2.2 知识与群记录

| 能力 | 怎么用 | 结果 |
|---|---|---|
| 搜项目资料 | “找一下关于……的文档” | 搜索项目文档、设计、日记、讨论，返回路径与片段 |
| 读文档 | “读一下这篇”“打开第 2 条” | 读取搜索到的 Markdown 全文 |
| 个人笔记 | “记一下……”“看看我之前记的”“把那条改成……” | 仅私聊可用，只对自己可见 |
| 查群历史 | “刚才群里聊了什么”“搜一下群里关于……” | 查项目主群最近消息，可按关键词过滤 |

### 2.3 协作

| 能力 | 怎么用 | 结果 |
|---|---|---|
| 选项确认 | 助手主动发选项卡片 | 点按钮、回复编号或直接文字回答 |
| 找助手/转接 | “谁能接手？”“转给编程助手”“转私聊跟进” | 列出可联络助手与群名片；转接只传摘要 |
| 交给其他助手任务 | “让……处理这个” | 对方收到任务并开始处理 |

### 2.4 编程任务

| 能力 | 怎么用 | 结果 |
|---|---|---|
| 提交任务 | 主群 @ 或私聊提交，可带截图 | 交给编程助手执行，图片最多 4 张 |
| 新开任务 | “开个新任务” | 新建一个编程任务线程，不影响之前的任务 |
| 任务列表/状态 | “现在有哪些任务？”“编程助手能用吗？” | 列出任务与运行状态 |
| 进度/历史 | “进度怎么样？”“之前做到哪了？” | 读取任务输出与历史 |
| 继续任务 | “继续上一轮” | 在同一任务线程继续 |
| 待确认/审批 | “有什么要我确认的？”；回复 1/2/3/4 | 列出待办；1 允许本次 / 2 记住本会话 / 3 拒绝 / 4 拒绝并终止 |
| 停止任务 | “停一下” | 中断当前任务 |

## 三、总体使用方法

群里 @ 助手，或直接私聊它即可开始。私聊直接发消息，首次通常会自动开通，只服务你本人，项目由管理员配置。

### 3.1 在项目主群

- @ 助手提出项目问题；平台允许时，助手也会关注群讨论，只在话题与项目直接相关时接话。
- 被 @ 后会等约 2 秒合并消息；讨论较多时集中处理，不一定秒回。
- 可以提交开发需求，但只有明确要改代码、查代码、构建或验证时才提交；需求说不清会先问一句。
- 群内回复通常控制在 300 字以内，细节可以转到私聊。
- 群聊公开，不要发账号、密钥、私人聊天截图。

### 3.2 在仅 @ 群

- 只有 @ 助手才会回复；普通消息只进入上下文，不会触发回答。
- 适合项目相关提问和讨论，不接开发任务，也不做转接。
- 被 @ 后会短暂合并消息，回复通常比较简短。

### 3.3 发图片和文件

- 可以直接发截图，助手会读取图片内容。
- 网页、日志、文档优先发链接或粘贴文本，避免超大附件。
- 发送的图片会被助手读取，用于理解和回答。
- 在项目主群发图等于公开，注意先脱敏。

### 3.4 记住你的偏好

在私聊里说“记一下：……”，例如“记一下：以后回答尽量简短”“记住我负责的模块是……”。之后说“按之前记的来”即可。记错了就说“把刚才那条改成……”或“忘掉……”。个人笔记只对自己可见，群助手不能写。

### 3.5 把需求转给合适的助手

- 项目主群需要单独跟进时，可以让助手把你的需求转给私聊助手；它只转摘要，不转完整聊天记录。
- 仅 @ 群不做转接。
- 私聊里也可以把需求交给更合适的助手；之后由接手的助手回复你。

## 四、交互规则

- 项目主群：被 @ 时一定回复；项目相关话题可能接话；普通闲聊一般不插嘴。
- 仅 @ 群：只有被 @ 才触发，普通消息只作为上下文。
- @ 之后会短暂等待并合并消息；群讨论较多时会成批处理；私聊消息逐条处理。
- 群内回复一般在 300 字以内，私聊可以稍长。
- 长任务通常先回一句“收到”，完成后再汇报，不会全程刷屏。
- 助手不会编造结果；不会透露工具名、路径、审批配置等内部细节；不会把你的私聊转发给别人。
- 平台对私聊连续回复有限制，消息太多时可能延迟或被限制。

## 五、隐私与安全

- 群聊内容所有人可见。账号、密码、密钥、身份证、私人聊天截图不要发到群里。
- 私聊只属于你和助手；转接时也只传递摘要。
- 审批：项目主群由管理员处理，私聊由你本人处理。
- 编程助手只在限定的项目目录内工作；越出范围的敏感操作需要审批。
- AI 可能出错。重要结论请复核；涉及金钱、法律、医疗等事项，请咨询专业人士。
- 生成的文字、图片请自行确认版权与合规；不要用于违法、侵权、骚扰或泄露他人隐私。

## 六、常见问题

**@ 了没反应？**  
仅 @ 群必须 @；项目主群可能正在处理上一轮、消息被合并，或平台网络波动。稍等后重试；仍无响应请联系管理员。

**项目主群为什么普通消息不回？**  
项目主群以项目讨论为主；闲聊、水群和无关内容可能不会接话。

**为什么回得慢？**  
群消息在合并，或任务在排队、执行中。长任务需要时间，完成后会主动汇报。

**私聊会被别人看到吗？**  
不会。只有你和助手可见；转给其他助手时只传摘要。

**主群提交的任务谁来审批？**  
项目主群由管理员确认；私聊任务由你本人确认。回复 1 允许本次、2 允许并记住本会话、3 拒绝、4 拒绝并终止本次任务；支持卡片时直接点按钮。

**任务做到一半能停吗？**  
可以，直接说“停一下”或“取消这个任务”。

**它说完成了，但我没看到变化？**  
让它给出改动文件和验证方式；仍有疑问可请管理员复查。

**能换一个项目吗？**  
私聊绑定的项目由管理员配置；项目主群固定围绕本项目。需要调整请联系管理员。

**它能踢人、禁言或发群公告吗？**  
一般不具备群管理权限，只负责对话和任务。

## 七、使用建议

- 项目主群：@ 后直接说事；细节转到私聊，避免刷屏。
- 报错优先发截图、报错原文和时间。
- 大任务拆成小步，逐步确认。
- 主群任务可能需要管理员审批，耐心等结果。
- 重要结论可以让助手记进个人笔记。

## 八、能力边界

- 以项目工作为主，不是通用闲聊机器人；无关话题可能不回复。
- 私聊项目由管理员配置，不能自行切换。
- 审批、构建和长任务需要时间，不保证秒回。
- 部分能力需要开通，未开通时无法使用。
- 平台自身有限制，私聊连续互动过多时可能延迟或受限。
- 助手不能替代人工判断和最终审核。
